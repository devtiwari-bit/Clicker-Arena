🎮 Clicker Arena

⚡ Test Your Speed. Beat Your Record. Become a Legend!

Welcome to Clicker Arena, a fast-paced browser clicking game developed by Ved Games Production. Test your clicking speed, improve your reflexes, compete against your personal best, and climb the ranks from Rookie to Speed God!

🌐 Play Now: "Clicker Arena" (https://devtiwari-bit.github.io/Clicker-Arena/)

---

✨ Features

- 🖱️ Fast-Paced Gameplay — Click as quickly as possible before time runs out.
- ⏱️ Multiple Game Modes — Choose from 10, 20, or 30-second challenges.
- 🏆 Ranking System — Progress through ranks as your score improves.
- 🎯 Achievements — Unlock achievements while playing.
- 🔥 Combo System — Build combos with consecutive clicks.
- 📊 Personal Best — Save your best performance locally in your browser.
- 🔊 Sound Effects — Enjoy audio feedback during gameplay.
- 🌌 Neon Gaming Design — A modern, dark-themed interface with animations.
- 📱 Responsive Layout — Play on supported desktop and mobile browsers.
- 🚀 No Installation Required — Play directly in your web browser.

---

🕹️ How to Play

1. Open the "Clicker Arena website" (https://devtiwari-bit.github.io/Clicker-Arena/).
2. Select your preferred time mode.
3. Start the game.
4. Click the target as many times as you can before the timer reaches zero.
5. Check your score, rank, achievements, and personal best.
6. Play again and try to beat your previous record!

---

🏅 Ranking System

Your performance determines your rank. Keep practicing, improve your clicking speed, and aim for the highest rank available in the game.

---

🛠️ Built With

- HTML5 — Game structure
- CSS3 — Styling, animations, and responsive design
- JavaScript — Game logic, timer, scoring, sounds, and achievements
- Web Audio API — Browser-generated sound effects
- Local Storage — Saving personal bests and achievements

---

💻 Run Locally

Want to run the game on your computer?

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.
4. Start playing!

No installation or additional dependencies are required.
